# of wheels plus a ~90 MB model. Railway's free container has 512 MB of RAM
# and a 1 GB disk, so installing them either OOMs the service or leaves no room
# for the app itself.
#
# Everything heavy has a cheaper path:
#   TRANSLATION_BACKEND=groq   translation via Groq instead of local NLLB
#   retrieval.py               falls back to pure-Python lexical ranking when
#                              sentence-transformers is absent
#
# Install them only on a machine with headroom:
#   pip install -r requirements-nllb.txt
#   scripts/verify_build.py     # asserts the app still works without them
